# Lab06: ERC 20 + Hardhat

- Triển khai ERC 20 token contract trên mạng Hardhat

- Nhập token contract vào ví Metamask
- Chuyển token giữa 1 số tài khoản.

cd Lab06-ERC20-on-Hardhat

npm i
