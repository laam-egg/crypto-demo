# Lab 04: HardHat Tutorial

## Đề bài

- Thực hành theo <https://v2.hardhat.org/tutorial>
- Đến bước 6
- (Option: bổ sung thêm bước 8, bỏ qua bước 7)

## Bài làm

Bài tập được thực hành trên hệ điều hành Ubuntu 22.04 (Linux Mint 21.3).

### Prerequisites

- Node.js 22+

### Setup & Run

```sh
cd Lab04-Hardhat/hardhat-tutorial
npm install
npx hardhat compile
npx hardhat test
```
